# 81年前的今天 日本签署投降书

1945年9月2日，日本代表在停泊于东京湾的美国“密苏里号”战列舰上，正式签署无条件投降书。这一仪式标志着第二次世界大战暨中国人民抗日战争最终胜利结束，也是世界反法西斯战争全面胜利的重要节点。

💡 **要点提炼**
- **历史坐标**：投降书签署为全球二战画上句号，中国战场作为东方主战场，牵制了日本陆军主力，为最终胜利作出不可替代的贡献。
- **法理意义**：该文件具有国际法效力，明确日本接受《波茨坦公告》，为其后续领土处置及和平宪法奠定法律基础。

签署仪式上，日本外相重光葵和参谋总长梅津美治郎分别代表日本政府及大本营签字，随后盟军最高统帅麦克阿瑟及美、中、英、苏等九国代表依次签署。中国作为战胜国代表徐永昌将军出席，见证了这一历史时刻。81年后的今天，回望这段历史，不仅是纪念胜利与牺牲，更是警示和平之珍贵——前事不忘，后事之师，唯有正视历史，才能面向未来。
